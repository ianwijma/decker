## Merged PR18 contract (read docs/toggle-runtime.md in full)

Binding.toggle is {on:Target, off:Target, source:{kind:app,initial:on|off} | {kind:external,probe:Target,timeoutMs}}. Timeout is 10–60000 ms. Targets are existing action/sequence/workflow unions. Runtime identity is deckId/bindingId/generation. shared/binding-targets.ts visits ordinary phases and toggle.on/off/probe; credentials, imports, cloning and workflow aliases already use it.

Snapshot.toggles is an optional bounded array (4096) with deckId, bindingId, generation, confirmed:on|off|unknown, transitioning, reconciling, fresh, blocked and fixed error code. No raw result/error strings are exposed. Toggles service offers configure(document,activate?), press, reconcile, recover, snapshot, settled and stop. Busy presses/reconciliation are ignored, independent of ordinary binding queue policy. All inputs use configured binding identity; renderer/web input cannot supply arbitrary toggle targets. Engine.activeCount includes private probes under the global 64-run cap.

App state advances only on target success AND durable confirmation. External state advances from observation, never command completion alone. Unknown/stale/blocked state refuses ambiguous presses. Failed/cancelled/timeout transitions preserve confirmed state; external failure/timeout reconciles, cancellation does not automatically start another probe. Private RunHandle.result is bounded typed execution data; done remains redacted history. Never parse history to decide state. Valid probe outputs: native boolean; exact on/off string; workflow {on:boolean} only; or successful command envelope stdout trimmed to on/off/true/false, at most 1024 characters. Empty/malformed/oversized/error is not false.

Main owns separate toggles.json with bounded key/stamp/confirmed/pending records, journal-before-effect and atomic commit. Unknown pending effects block replay. Imports export configuration, not runtime state, and allocate fresh toggle identities. Relevant executable-definition/config changes invalidate in-flight operations; late completions cannot affect replacements. Preserve invocation-aware cancellation, pinned definitions/aliases, run activity independent of state and responsive cancel outside the main mutation queue.

Startup/runner restart and confirmed workspace import activate probes; parsing/review/export/copy/editing/ordinary saves do not. Reconfigured external bindings wait for explicit reconciliation/activation. Desktop requests activateToggles, reconcileToggle {deckId,bindingId}, recoverToggle {deckId,bindingId,confirmed} already exist. Use bounded trusted desktop paths; do not expose arbitrary commands/probe APIs or toggle store records to paired browsers.
